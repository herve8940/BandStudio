# Sécurité

La branche `main` reçoit les corrections. Installe les distributions uniquement depuis les Releases de `herve8940/BandStudio` et vérifie les empreintes publiées.

Pour un problème de sécurité, n’inclus aucun secret, projet personnel ni détail permettant une exploitation dans une issue publique. Utilise le signalement privé GitHub s’il est proposé dans l’onglet Security ; sinon demande un canal privé dans une issue sans détail sensible.

Les diagnostics restent locaux jusqu’à leur partage volontaire. Les projets et les archives importées doivent être traités comme des données non fiables. Les mises à jour de code n’incluent ni modèles ni runtimes ; une évolution de ces dépendances peut demander une réinstallation.
