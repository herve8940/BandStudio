Windows: extract the complete ZIP, then open BandStudio.exe. WebView2 is required. macOS: initial setup from source; updates for prepared installations on Intel and Apple Silicon. A complete macOS installer for a new computer is not yet distributed.

Versions and release notes ↗
Do I need an internet connection?

Yes, to install components and download updates. Song analysis and preparation run locally. Automatic updates can be disabled.

Are AI results final?

No. Separation can leave artifacts, and chords, lyrics or sections may need editing. You listen and review before sending the song to REAPER.

What are the current limitations?

The available models determine which instruments can be separated. Advanced sub-stems are not provided for every instrument. Windows audio devices and optional engines need to be checked on your computer.

How do I report a problem?

In Settings, export a diagnostic and open “Report a bug on GitHub”. Review the file before attaching it. Logs stay local until you share them.

What about model licences?

BandStudio code is MIT-licensed. Components keep their own licences; some optional structure or drum models are restricted to noncommercial use. Read the licences.
