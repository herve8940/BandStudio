# BandStudio 1.1 · Mise à jour du 25 novembre 2026

- Dans **Paroles** ou **Régie QLab + grandMA3**, appuie sur **M** pendant la lecture pour marquer le passage que tu entends. Donne un nom au repère et valide avec **Entrée**. Dans la conduite de régie, tu peux réécouter le passage et ajuster le repère à l’image près.
- Pour préparer un concert, choisis les morceaux dans leur ordre de passage. L’export de régie crée un groupe par titre pour QLab 5, des séquences pour grandMA3 et une piste audio de timecode LTC. Le fichier README de l’export indique comment charger la conduite et affecter les sorties.
- **Projet Ableton Live** exporte un Set Arrangement par morceau avec les pistes, le mix, les repères et les changements de tempo. Garde le fichier `.als` et son dossier `Samples` ensemble.

## English

- In **Lyrics** or the **QLab + grandMA3** view, press **M** during playback to mark the moment you hear. Name the marker and press **Enter** to save it. In the show rundown, you can audition the passage and move the marker one frame at a time.
- To prepare a concert, select the songs in show order. The export creates a group per song for QLab 5, sequences for grandMA3 and an LTC audio track. The exported README explains how to load the show and route the outputs.
- The Ableton Live export creates an Arrangement Set per song with tracks, mix settings, locators and tempo changes. Keep the `.als` file alongside its `Samples` folder.
