# Métronome régulier, accords et noms des morceaux

- Le métronome conserve un tempo constant sur toute la durée du morceau, y compris avant les premiers temps détectés, dans les silences et jusqu’à la fin. Les subdivisions, les décomptes, le tempo de scène et l’export REAPER utilisent cette même pulsation. Les anciens guides sont régénérés automatiquement ; les sections et les analyses enregistrées sont conservées.
- La bibliothèque propose **Renommer** sur chaque morceau. Le nom est actualisé dans le morceau ouvert et les setlists ; les fichiers audio et le dossier du projet gardent leurs chemins.
- La recherche d’accords reconnaît les métadonnées contenant aussi bien « Artiste – Titre » que « Titre – Artiste ». Le catalogue passe de 13 à 22 sources, dont 8 connecteurs automatiques. KhmerChords, Chords and Tabs et Ukulele Tabs rejoignent les sources récupérables ; les autres nouvelles entrées proposent une recherche ciblée dans le navigateur.
- Les exports REAPER utilisent des chemins courts compatibles avec Windows, même pour les longs titres YouTube. Le fichier RPP, ses pistes audio et les fichiers temporaires restent dans des chemins limités ; si le dossier du morceau est trop profond, l’export est placé dans le dossier Exports de la bibliothèque. Le titre complet est conservé et restauré lors du réimport. Les exports existants ne sont pas remplacés.
