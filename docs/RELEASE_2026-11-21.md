## Correctif du 22 novembre · retrait du recalage forcé des sections

Le recalage des sections sur les mesures et la préférence forcée pour des longueurs paires sont retirés. L’analyse des sections et l’export REAPER retrouvent leur comportement antérieur. Les fiches écran et PDF conservent chaque mesure en une seule case, avec un repère interne lorsque la section change au milieu : leur affichage ne déplace pas la musique.

Pour les projets touchés par la précédente mise à jour, Mac et Windows restaurent les sections de `Backups/section-grid-v1/project.json` seulement si la grille et les sections correspondent encore exactement au résultat de cette migration. Toute modification ultérieure de section ou de grille bloque cette restauration automatique ; sans sauvegarde fiable, le projet reste inchangé. L’état courant est sauvegardé dans `Backups/section-grid-rollback-v2/project.json`. Les paroles, les médias et les réglages d’écoute sont conservés. Les guides sont régénérés lorsque les sections ont été restaurées.

Les paroles automatiques d’une ancienne analyse sont actualisées une fois à l’ouverture, si le moteur Paroles est installé. Le texte est comparé aux références et recalé localement sur le chant ; les paroles corrigées manuellement sont préservées. Le fichier original reste dans `Backups/lyrics-alignment-v1/project.json`. Le traitement reste annulable et son résultat indique les calages incertains. L’absence de référence n’invente pas de paroles.

Les projets REAPER déjà exportés restent inchangés : réexporter le morceau pour retrouver les sections restaurées.

## 22 November patch · withdraw forced section alignment

Forced whole-bar/even-length section alignment is removed; analysis and REAPER export return to their prior behavior. Screen/PDF charts still show each bar once, marking internal section changes without moving them. Affected projects are restored from their original v1 backup only when their grid and sections still exactly match that migration; later section/grid edits, missing backups and invalid backups are preserved. Current documents are backed up before recovery. Lyrics, media and listening settings remain unchanged; guides rebuild after restoration. Improved automatic lyrics correction is retained. Existing REAPER exports must be regenerated to include restored sections.
