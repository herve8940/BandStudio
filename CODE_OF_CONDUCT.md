# Notre communauté

BandStudio accueille tous les musiciens et contributeurs, quel que soit leur niveau. Échange avec respect, critique les idées et le code plutôt que les personnes, et accepte les corrections de bonne foi.

Le harcèlement, les insultes, les discriminations et le partage de données privées ne sont pas acceptés. Les responsables du dépôt peuvent modérer les échanges pour préserver un espace de collaboration utile et accueillant.
